# BodyMap Health

A Next.js + TypeScript + Tailwind prototype for viewing synthetic examination findings by body region.

## Run locally

Install Node.js 20+ and then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Safety & privacy

The included data is synthetic. This interface is informational only and is not a diagnosis or a substitute for professional care. Before accepting real reports, implement authenticated per-user authorization, private storage, deletion workflows, and server-only secrets.
